# Memory

## Overview

Memory represents durable cognition.

Memory stores knowledge that persists beyond active Sessions.

## Examples

- learned topology
- previous incidents
- operational facts
- historical knowledge

## Characteristics

Memory:
- persists
- evolves
- may influence future Sessions and Tasks
- **influences future perception policies** (adaptive layer)

## Role in Perception

Memory is not just passive storage. It is an **active feedback mechanism** for the perception system:

- **Learned signal importance**: signals that historically led to useful cognition are reinforced
- **Historical relevance**: patterns from past Sessions and Tasks inform what to watch
- **Signal decay**: irrelevant signals are gradually deprioritized
- **Reinforcement**: useful observations are strengthened over time
- **Forgetting**: irrelevant signals are actively suppressed

This makes perception adaptive: an agent's memory of what was useful in the past shapes what it pays attention to in the future.

## Distinction

Memory is durable.

Session is active and temporary cognition.
