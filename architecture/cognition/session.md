# Session

## Overview

Session represents shared working cognition.

A Session is a bounded area of active reasoning and operational focus.

## Examples

- investigation
- incident analysis
- migration
- debugging
- maintenance activity

## Characteristics

Sessions may contain:

- reasoning
- temporary notes
- tool outputs
- hypotheses
- participants
- execution context

## Distinction

Session is not Memory.

Session represents active cognition.

Memory represents durable knowledge.

## Role

Sessions often emerge from observations and may create tasks or durable knowledge.
