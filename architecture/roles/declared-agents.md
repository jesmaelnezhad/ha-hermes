# Declared Agents

## Overview

Not all Hermes agents are native platform roles.

Some agents are intentionally declared by users after bootstrap to represent application and infrastructure cognition.

## Native Roles

Native roles are part of HA-Hermes bootstrap.

- Warden
- Regent

## Declared Roles

Declared roles are user-defined cognitive operators.

- Steward
- Emissary

Their responsibility emerges from declaration scope and placement.

## Principle

Responsibility is not a separate artifact.

Responsibility emerges from:

- agent type
- placement
- scope

## Examples

A Steward declared for a namespace becomes responsible for that application domain.

An Emissary declared for a host becomes responsible for that external environment.
